# Development

## Setup

```console
make install   # uv sync --locked into .venv
make hooks     # prek git hooks
make help      # every target, by section
```

## Layout

| Path | Contents |
| --- | --- |
| `src/wow/_async/` | The client and resources, written async. The source of truth. |
| `src/wow/_sync/` | Generated by `make generate` from `_async`. Never edit by hand. |
| `src/wow/_base.py` | I/O-free pieces shared by both: retry policy, token parsing, request parameters. |
| `src/wow/models/` | One module per Battle.net API, built from recorded responses. |
| `tests/fixtures/` | Recorded responses served by the mocked Battle.net in `tests/conftest.py`. |

## Checks

`make ci` runs what CI runs:

- `make check`: ruff lint and format, pyproject-fmt, codespell, the generated-code check, and pyrefly in strict mode.
- `make test`: pytest with branch coverage, which fails below 100%.
- `make docs`: Sphinx with warnings as errors.
- `make build`: sdist and wheel.

Every test using the `client` or `make_client` fixture runs three times: against the sync client, and against the
async client under asyncio and under trio. Tests should assert behavior a user would notice; coverage gaps are closed
with such tests or by deleting the code.

## Type checking

Pyrefly runs with the `strict` preset against `pyrefly-baseline.json`. Errors recorded there are accepted; anything
new fails. `make type-baseline` rewrites the baseline, so review its diff like code.

## Fixtures

`make fixtures` re-records `tests/fixtures` from the live API with `BATTLENET_CLIENT_ID` and
`BATTLENET_CLIENT_SECRET` set. Realm and account fixtures are transcribed from community probing until Blizzard
serves them; they carry a `source` key saying so.

## Releasing

1. Bump `version` in `pyproject.toml` and move the changelog's Unreleased entries under the new version.
2. Merge to `main`. CI builds and checks the dist and stores it as an artifact named after the commit.
3. Publish a GitHub release tagged `v<version>` on that commit. `publish.yml` downloads that exact artifact, verifies
   its checksums and publishes it to PyPI through Trusted Publishing.
